# Mini Projeto Lanchonete

Aplicação de console desenvolvida em C# para simular o funcionamento básico de um sistema de pedidos de uma lanchonete.

Este projeto foi desenvolvido com o objetivo de praticar lógica de programação e registrar minha evolução no aprendizado de C# e .NET.

## Funcionalidades

- Visualização do cardápio;
- Adição de produtos ao pedido;
- Definição da quantidade de cada item;
- Visualização do resumo do pedido;
- Cálculo do subtotal de cada produto;
- Cálculo da quantidade total de itens;
- Cálculo do valor total do pedido;
- Remoção de itens do pedido;
- Finalização do pedido;
- Validação de opções e quantidades informadas pelo usuário.

## Tecnologias utilizadas

- C#
- .NET 10
- Aplicação de console
- Visual Studio

## Conceitos praticados

- Variáveis;
- Tipos de dados;
- Vetores;
- Estruturas condicionais;
- Estrutura `switch`;
- Laços de repetição `for` e `while`;
- Validação de dados;
- Operações matemáticas;
- Interação com o usuário pelo console;
- Organização de um fluxo básico de pedidos.
